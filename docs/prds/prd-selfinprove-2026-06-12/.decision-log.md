## D-009 — Vision 1 答: 节律处理 = 默认 out-of-session + 手动 in-session (2026-06-12, 大湿 "用户每天其实使用的时候不一定要在session里面去处理整理出来的内容项目")

**大湿原话 (per P3)**: "用户每天其实使用的时候不一定要在session里面去处理整理出来的内容项目，按道理来讲去处理日月周报这个过程，是不会在session中处理的。但是如果用户手动要求整理也能整。也就是说agent要能手动处理周日月报数据。"

**决策**:
- **Out-of-session (默认)**: AutoDream 后台跑, 用户不在线时也整理; 用户回到 UI 在 Journal/Inbox 逐条审查。这是主路径。
- **In-session (manual)**: 用户在 Chat 主动触发 (例如 "整理本周日报" / "现在给我月报"), agent 在 session 内即时调用 AutoDream 子流程跑一次。这是补充路径, 不是默认。
- 节律配置 (daily/weekly/manual) 仅控制 out-of-session 触发频率; manual 始终可用。

**影响 §5 FR 设计**:
- 新增 FR: manual trigger 入口 (Chat 命令 + 卡片按钮) — 必含 FR
- 现有 AutoDream PRD FR-1~9 的 trigger adapter 必须支持同步 (sync) 调用模式, 不能只支持 cron
- 旧 "trust & safety 5 复选" 中 "deprecation" 那条跟 manual 强相关, 必须保留 (用户手动 deprecate proposal 是主要撤销手段)
