## Verification

Run the clean Windows sealed desktop build and Inspect commands from the checked build report, then install the prepared package and execute the acceptance checklist. Re-run DIVA replacement CI and VIVY required CI only for source changes since W6; package identity and clean-install tests still run on the final binary.

Expected evidence: Engineering evidence contains exact final source/artifact identities, clean-installed behavior and pending signing/platform rows. Owner acceptance is an independent record linked to that same artifact.

Implementation logs use
`docs/logs/2026-10-wails-migration/<story-id>-<iteration>/` in the repository
that changes, with summary.md, verification.md, release.md and acceptance.md.
Record unavailable environments and the next concrete evidence owner as pending.

## Exit gate and handoff

The prepared final Windows artifact passes engineering requirements and the owner signs off on the installed-product checklist. Other platforms are only declared supported with their own native evidence. Release publication is not implied by this gate.

## Review focus

Check final installed binary matches sealed/signed report, no implicit old state or DLL dependency, credential handling, owner-vs-engineering evidence and scope of release authorization.
