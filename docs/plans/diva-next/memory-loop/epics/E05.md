## 进入与退出

- 进入：每个 Story 按其直接前置证据进入，允许先准备不依赖前置的资料。
- 退出：所有所属 Story 达到 Done，来源版本兼容且无破坏 Epic 目标的 P0 遗留。
- 不计通过：计划完成、UI 按钮存在、fake backend 成功、旧候选的历史测试。
