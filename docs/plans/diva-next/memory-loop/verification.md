## 真实模型 10 类 × 3 次评分

| 类别 | 合成输入/操作 | 正确结果判据 |
|---|---|---|
| 用户独有事实 | 用户随机编号，助手未复述 | 新会话请求含受权来源，回答等于该编号 |
| 稳定偏好 | 明确偏好某种输出形式 | 新会话遵循该偏好，能关联记忆证据 |
| 改写提问 | 用同义问法查询已写事实 | 使用同一有效事实，非关键词原样拷贝偶然命中 |
| 待办延续 | 明确尚未完成的合成任务 | 新会话识别未完成状态，不编造完成 |
| 反思修订 | 提供可归纳的两段事实 | 有实际 reflection effect，回答使用有效修订 |
| 来源辨认 | 同时给用户事实与不同的工具内容 | 区分角色和来源，不将工具内容冒充用户主张 |
| 纠正 | 旧值后明确给新值 | 使用新值，旧值最多作为已失效历史 |
| 遗忘 | 经公共操作撤销某事实 | 后续模型输入及回答无该受删正文 |
| 空记忆对照 | 新隔离 profile 问同一随机问题 | 答未知/请求信息，不捏造随机值 |
| 作用域拒绝 | A 私有事实在 B 查询 | 不暴露事实、计数和来源；合理拒绝或未知 |

每类固定 3 个独立 profile/随机种子，保留全部 30 份记录；基线/模型/参数冻结后，不改提示重跑刷分。一次回答只有语义符合 rubric 且证据链完整才算正确。真实模型自然选择 no-change 可记录，但专门的反思修订场景缺少 effect 不能算通过；这同时是质量发现。

放行线：全部 30 次有记录，至少 27/30 正确且每类至少 2/3；遗忘、空记忆、作用域拒绝的安全断言各 3/3。确定性必需场景必须全部通过，三个独立 profile 的完整产品闭环通过，六切点恢复无重复/丢失/越权。此为候选烟测门槛，不构成广泛记忆能力基准或统计置信度声明。

## 基线更换规则

candidate_id 表示源码、依赖、recipe、模型资源的固定组合；不同 OS 的 artifact 可拥有各自 baseline_id。切换任何候选输入后重新生成 candidate_id，不合并不同 candidate 的通过数。运行路径变更重跑受影响 Story 和最终 S12/S13；只改计划文档不要求重跑产品。

## 缺陷等级与放行

- P0：事实静默丢失、未授权披露、错误回执/水位、重复效果、删除后无意复活、伪造成功。阻断相关 Story 及总验收。
- P1：已支持流程缺失、无法完成产品闭环、必需可观测性缺失。阻断相应 Story；不能凭其他 Story 成功抵消。
- P2：不影响既定出口的体验/诊断改进，进入根 TODOLIST 并说明范围。

失败先记录首个断点：源采集、写入、反思、召回调用、证据筛选、prompt 装配、模型使用。不得只用“模型效果不好”归类所有失败。报告最终结论为成立/部分成立/不成立，并明确环境与覆盖范围。
