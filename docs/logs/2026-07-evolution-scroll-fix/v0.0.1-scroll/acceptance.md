# Acceptance

## Acceptance Steps
1. Re-compile and start the desktop app (`just start` or `npm run dev`).
2. Navigate to the "Evolution" (进化) page.
3. Observe the Layout: Make sure the page correctly fills the remaining space.
4. If there is enough content in the Inbox list or any panel to overflow the container, use the mouse wheel to scroll down. The scrollbar should properly constrain to the internal panel area without clipping off the bottom.
