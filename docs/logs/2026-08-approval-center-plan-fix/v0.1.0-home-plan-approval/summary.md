# 主页审批中心计划批准修复

## 变更

- 修复主页统一审批中心的计划 `allow` 路径：批准后复用聊天页已有的计划批准、运行态同步和执行续接链路。
- 从审批资源和计划报告解析源会话，审批前校验计划报告仍然匹配，避免批准错误会话或过期计划。
- 后端批准成功后立即同步执行态；流启动失败时保留计划执行上下文，并在源会话提供“继续执行”恢复入口。
- 执行启动失败时关闭已消费审批的抽屉，避免待审批过滤器遮挡恢复入口。
- 删除审批卡片中不可达的 `applyAtSource` 分支及对应未使用翻译键。

## 影响范围

仅影响 `agent-diva-gui` 的主页审批中心、计划执行状态同步和恢复提示；其他审批域仍使用原有统一 `decide_approval` 路径。
