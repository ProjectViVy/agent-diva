# Summary

Removed the "Periodic" group from the GUI Persona & Memory (Laputa) section list.

The periodic entries (Daily, Weekly, Monthly) are already managed by the Notebook, so showing them again in Persona & Memory was redundant. The remaining groups in Persona & Memory are now Persona, Memory, and Indexes.

Unused translation keys for `laputa.groups.periodic` and `laputa.sections.daily/weekly/monthly` were also removed from the Chinese and English locale files.
