# Acceptance

本次决策记录满足以下验收条件：

1. BML 是普通长期 Memory 的唯一生产权威，不保留文件型 LTM 双权威。
2. `MemoryMd/memory_md` 的代码、API、GUI、Proposal、Prompt、迁移和 fallback 全部列入
   非兼容删除范围。
3. STM 明确定义为跨 session 的当前目标、开放回路、下一步、约束和证据指针工作集。
4. STM 有界且自动收敛，不成为第二个长期记忆库。
5. session checkpoint 与 STM 是两种生命周期，必须拆类型、命名和 GUI 表达。
6. STM 日常自动更新和用户修正不经过 Approval、Proposal 或 Governance。
7. Memory 页面拥有唯一 STM 状态入口和完整工作区；Persona/Evolution/Notebook 删除旧入口。
8. 物理存储、schema、自动化、并发、淘汰、历史、晋升和 Layer 1 装配保持待调研，未被
   文档擅自提前实现化。
