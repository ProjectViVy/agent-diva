# Garden 记忆工作台批次 · Acceptance

## 产品视角验收步骤

1. **导航拆分**：启动 GUI，侧栏「能力」组下应有「人格」与「记忆」两个平级入口；「人格」进入 Frozen Core 编辑（原 persona-memory），「记忆」进入记忆仓库
2. **治理树对齐**：人格页顶部架构树显示 Garden → Laputa / BML 两个子节点；点击 BML 节点或「打开记忆工作台」按钮跳转记忆版块
3. **记忆仓库浏览**：记忆版块展示记忆列表（内容摘录 + 类型徽标 + 时间）；点击条目右侧展示详情（内容、信任度、敏感度、置信度、来源、证据、取代记录等）
4. **搜索与过滤**：输入关键词触发搜索（FTS5）；类型下拉可过滤
5. **受治理删除**：详情页点「删除」→ 弹出原因输入框（必填）→ 提交后 toast 提示，自动跳转 Evolution 审批中心，新提案出现在 inbox（PendingReview）
6. **不直接删除**：审批前在记忆仓库中该条记录仍可见（proposal 未 apply）；批准后在仓库中消失
7. **错误态**：后端未启动时记忆版块显示错误信息与空态，不崩溃
