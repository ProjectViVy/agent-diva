# Detailed architecture delivery

The owner explicitly requested supermanagement + Superpowers detailed design.
DN-C2 replaces DN-C1 in the existing design and contract ledger; stage/index
and active backlog references are synchronized. No second plan package.

Design covers one-runtime ownership, same-owner Garden public extension,
generated cognitive assembly, transport-attested human authority, FrozenCore
in actual model input, per-run Mission pins, durable capture/watermarks and
unknown-outcome recovery stops. Chat/OBS consumers use verified producers.
Online voice uses DIVA/Tauri credentials/cloud HTTP and Raw WAV/MP3 IPC with
context fencing, bounded reference assets and no persistent audio queue.

New engineering gaps recorded: supervisor primary capture risk, service-lifetime
Mission pin/failed-attempt recovery, transitive sibling build replacements and
native dependency closure. These were identified by source inspection, not
reported as reproduced installed failures. Mentle is the first supported
Garden adapter, selected explicitly in a fresh profile; no silent BML switch.

English repository documents and local commit; Chinese conversation. Product
code, instruction files, external issues, remote branches and releases are not
changed. Implementation/native/cloud validation remains pending.
