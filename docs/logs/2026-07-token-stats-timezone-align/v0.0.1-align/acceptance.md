# Acceptance

## Steps
1. Recompile and start the desktop app.
2. In Token Statistics, view the `1d` (1 day) tab.
3. Verify that the chart timeline exactly spans from `00:00` of the current local day, up to the current time, with bars appearing every 30 minutes.
4. Verify that missing segments in the timeline still render as flat lines (0 tokens) in 30-minute intervals.
