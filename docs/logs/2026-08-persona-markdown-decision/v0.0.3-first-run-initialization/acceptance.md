# Acceptance

本次决策记录满足以下产品验收条件：

1. 首次问题完整覆盖 Agent 身份、用户与关系、初始承诺/红线、成长偏好和当前环境。
2. WORLD 参加初始化，但保持独立 claim 权威，不成为第五个 Frozen Core。
3. 只有五份权威全部不存在时显示首次引导；全存在后永久不再显示。
4. 部分存在、空文件或损坏进入修复状态，不重新初始化或覆盖已有内容。
5. 初始化一次原子直写五份权威和首批历史，不经过 Proposal、Approval 或 Governance。
6. 初始化失败不进入 ready、不留下半套权威，并保留用户全部输入。
7. Relationship 承载初次关系理解；Commitment 承载 Agent 不得自行解除的承诺与红线。
8. 当前 Persona 可以修订，但每次真实变化都永久追加不可变历史版本。
9. 历史恢复形成新版本，不删除中间轨迹；no-op 和拒绝请求不伪造文档 revision。
10. 完整历史只用于审计/浏览，不整体注入模型上下文。
