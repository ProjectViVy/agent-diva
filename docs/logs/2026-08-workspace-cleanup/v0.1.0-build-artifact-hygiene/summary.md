# 工作区清理与构建产物隔离

本迭代整理仓库的构建产物边界，避免 Rust、前端和 Tauri 的本地生成文件进入待提交变更。

- 将 Rust `target/` 规则扩展为递归匹配，覆盖根工作区和嵌套参考工作区。
- 将 Tauri `src-tauri/gen/`、资源二进制和 manifest 生成目录统一纳入递归忽略。
- 移除历史误提交的根目录 `build.json`（Cargo `compiler-artifact` 输出）；同类文件现在会被规则拦截。
- 保留源码、锁文件、归档资料和 `docs/logs/` 文档；没有删除任何用户文件或本地缓存。
- 当前未发现未被忽略的未跟踪文件。
