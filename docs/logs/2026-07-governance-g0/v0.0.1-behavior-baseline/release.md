# G0 Release Notes

This is a test-and-documentation baseline. It introduces no production API,
configuration, persistence, or runtime behavior change.

Release consists of three focused commits:

1. Agent/Manager characterization and contract fixtures.
2. GUI capability ledger and validation.
3. Authority inventory, product decisions, contract matrix, verification, and backlog reconciliation.

No migration, deployment, remote push, or feature flag is required. G1 remains
blocked until the full workspace gate is green. Rollback is the normal revert of
the corresponding focused commit.
