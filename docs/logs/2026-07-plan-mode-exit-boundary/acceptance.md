# Acceptance

1. Enter Plan mode in a chat and explore without producing a valid plan report; verify the UI remains in Plan mode.
2. Produce a report and reopen another conversation; verify the other conversation does not inherit the report or switch mode.
3. Approve the report in its original conversation; verify that conversation switches to Agent mode and begins execution.
4. Reopen the executing conversation; verify the execution report is restored only for its own session.
