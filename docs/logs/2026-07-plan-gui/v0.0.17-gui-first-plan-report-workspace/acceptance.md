# Acceptance

1. Open a pending plan: it is presented as a report with revision and report detail, not an approval-time TODO generator.
2. Select retain, compact, or clear: the UI states that the selection is pending runtime implementation.
3. Approve without a TODO list: the active bar says there is no execution list rather than rendering fake progress.
4. Complete or cancel a TODO: it no longer appears in the active queue, while plan history continues to show the parent plan.
5. Open the plan overlay: it is labeled as plan history and no longer exposes inline deletion.
