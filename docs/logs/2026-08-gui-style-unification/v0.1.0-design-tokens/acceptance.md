# Acceptance: GUI 样式体系统一 v0.1.0

**日期**: 2026-08-17

## 验收前提

构建桌面端：`just start`（或 `cd agent-diva-gui && npm run tauri dev`）。

## 验收步骤

### 1. 主题切换与持久化
- [ ] 设置中依次切换 love → dark → default → miku，界面即时变化，无白屏/闪烁。
- [ ] 切换后关闭并重开应用，主题保持不变。
- [ ] DevTools 中检查 `<html data-theme="...">` 与所选主题一致。

### 2. 聊天主界面（四主题各查一遍）
- [ ] 聊天区背景/文字、输入框、发送栏边框颜色符合该主题。
- [ ] 用户气泡与助手气泡配色、阴影正常。
- [ ] 头像与"我"的头像底色正常，悬停阴影生效。
- [ ] 空会话占位（图标+文案）颜色正常。
- [ ] Markdown 链接为信息蓝色、代码块深底正常。

### 3. 会话侧边栏
- [ ] 会话项悬停/选中态正常；搜索框聚焦描边为主题品牌色。
- [ ] 删除按钮悬停出现红色底 + 红字；右键菜单"删除"为危险红色。

### 4. 审批中心
- [ ] 输入栏右上角审批图标激活态为琥珀色描边；待办徽标红底白字。

### 5. 设置 → MCP 管理
- [ ] 服务器状态点：连接=绿、降级=黄、无效=红（切换 dark/miku 后色调随主题）。
- [ ] 错误提示框红底红字；危险操作按钮悬停红色底。

## 通过标准

以上观察点在四个主题下均无可见色差、错位或样式丢失；任一主题出现回归则按 release.md 回滚对应提交。
