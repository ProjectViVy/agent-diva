# 用户验收标准

1. 打开设置可以看到独立的“工作区”页面，能区分当前路径、来源和项目指令状态。
2. Topbar 能快速显示当前工作区 basename，并在详情中查看完整 canonical path。
3. 选择目录后，确认弹窗明确说明受影响的文件、Shell、Session、Plan、Subagent 与 AGENTS.md。
4. 流式回答、Plan 执行或待审批时切换会被阻止，不会出现半旧半新的运行状态。
5. 切换成功后 Gateway 重建，新的工作区路径和最近会话一致；失败时旧工作区仍可用。
6. 根目录存在 `AGENTS.md` 时显示“已注入”，不存在时显示“未发现”，超限时显示“已截断”。
7. GUI 不提供编辑 AGENTS.md、授予权限或迁移全部数据的隐式操作。
