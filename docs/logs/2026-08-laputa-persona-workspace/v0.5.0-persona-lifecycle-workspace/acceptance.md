# Acceptance

1. Open **Laputa - Persona** and confirm the Frozen Core, pending proposal, and current-session status strip uses live data.
2. Select a Frozen Core section, enter valid JSON and a change reason, and submit a proposal.
3. Confirm the proposal appears in the right lifecycle rail and can be edited, deferred, rejected, approved, or approved and applied.
4. After apply, confirm authority changes immediately while an already captured session is marked **effective next session**.
5. Start or reset the session and confirm it changes to **current authority active**.
6. Confirm the applied changelog can be rolled back from the lifecycle panel.
7. Open MEMRULES or WORLD and confirm it is read-only.
8. Confirm there is no old-setting scan, import, migration, or compatibility entry.
