# 蜜桃樱粉主题

Love 与 Default 使用 `#FFF8F6` 暖白作为页面底色，卡片使用白色，`#FFE3EA` 用于选中态和聊天消息表面。主操作使用 `#F28BA8` 并配深暖棕文字；按下状态使用 `#D9567B`，正文链接和主要强调文字使用更深的莓红 `#B83F65`。杏色 `#FFC8A2` 与薰衣草紫 `#C9B6F2` 只出现在轻量状态表面和夜间相关强调。

小字号的辅助文字从推荐的 `#8F7C82` 略压深为 `#806D74`，以保证浅暖白底上的可读性。Dark 采用 `#2A1F23` 暖棕背景、`#3A2A30` 卡片、`#FF9DB7` 粉色操作色与 `#F6E9ED` 正文。Miku 仍保留独立青色主题。

本次只调整现有颜色 token 与依赖主操作色的共用按钮/选中控件；不改变布局、导航、表单数据流或组件 API。
