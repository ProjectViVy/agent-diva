# 验收步骤

1. 启动 DIVA 桌面客户端或运行前端服务：`just gui-dev`。
2. 观察默认主题（Love / Default）界面视觉呈现：
   - 整体背景呈现干净舒适的暖白色 (`#FFF8F6`)，大面积呼吸感良好。
   - 文字呈暖深棕色 (`#3D2B31`)，清晰温润，长时间使用不易视觉疲劳。
   - 卡片、气泡与弹窗边缘圆润（16–24px 阶梯），过渡平滑。
3. 检查主操作按钮：
   - 按钮背景为 `#D9567B`，白色字体在深粉色衬托下对比度明显提高，字迹清晰。
   - 按钮 Hover 呈现温和的 `#B83F65` 加深效果。
4. 检查各主题隔离状态：
   - 进入 设置 → 主题，在各主题卡片间切换。
   - 验证 Miku 青色主题和 Dark 深色模式保持独立不受影响。
5. 检查应用启动页：
   - 查看 `public/splashscreen.html`，展示 `#FFB3C6 → #F28BA8` 柔和渐变爱心与进度条。
