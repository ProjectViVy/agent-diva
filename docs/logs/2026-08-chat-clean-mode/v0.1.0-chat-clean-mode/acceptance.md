# 用户验收

1. 打开“通用 → 聊天设置”，确认“清爽模式”默认关闭。
2. 打开清爽模式，确认三个自动展开开关不可编辑；关闭后确认原先的开关值恢复。
3. 在正常模式执行一个工具，确认工具消息显示“调用工具：工具名”，运行中显示三个点，完成后显示成功/失败状态。
4. 打开清爽模式执行普通工具，确认默认只显示工具名和状态，不显示输入参数或结果预览；点击“查看详情”后仍能看到完整参数和结果。
5. 执行或查看计划、TODO、审批工具，确认交互卡片仍然显示且可以操作。
6. 在聊天设置中切换自动展开思考、工具详情和元数据，确认已有消息立即同步；重新打开 GUI 后偏好仍保持。
7. 打开包含旧工具结果的历史会话，确认能够显示已持久化或从 assistant tool call 恢复的工具名称；无法恢复时显示“未知工具”。
