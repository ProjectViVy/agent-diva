# 聊天清爽模式与工具调用显示修复

## 变更内容

- 在“通用 → 聊天设置”新增默认关闭的“清爽模式”。
- 清爽模式暂时覆盖三个自动展开设置，但保留用户原值；关闭后恢复。
- 修复思考区由子组件私有状态控制导致的自动展开失效。
- 修复自动展开设置只在新消息进入时生效的问题，使设置变化立即同步到已有消息。
- 工具调用统一显示“调用工具：工具名”，运行中显示三个进度点，完成后显示成功/失败状态。
- 清爽模式默认隐藏普通工具的输入与输出，但仍允许手动展开详情；计划、TODO、审批等交互卡片继续显示。
- 工具结果持久化时写入工具名称，并为旧历史从 assistant tool call 反推工具名。

## 影响范围

- GUI 聊天设置、聊天消息渲染、思考展开状态和历史消息映射。
- Agent 工具结果消息的进程内名称字段及会话持久化结果。
- 不改变工具执行、权限、结果存储或后端事件协议。
