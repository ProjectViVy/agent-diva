# Acceptance

1. Launch DIVA desktop or start the frontend via `just gui-dev`.
2. Observe the main application interface under the default theme (Love / Default):
   - Page background displays a clean, soft warm white (`#FFF8F6`) rather than harsh pink or pure white.
   - Text is rendered in gentle deep warm brown (`#3D2B31`) with clear contrast and reduced eye strain.
   - Borders and dividers show a subtle light pink-gray (`#F3E4E7`).
   - Cards and elements use softer, rounder corners (16–24px curvature).
3. Check primary buttons (e.g. settings save buttons, provider wizard buttons, decision card approval buttons):
   - Buttons display high-contrast white text against the primary dark background (`#D9567B`).
   - Button text is crisp, legible, and easy to read.
4. Check chat bubbles in conversation view:
   - Diva's assistant messages display on a soft `#FFE3EA` background with dark text.
   - User messages display in high-contrast pink-rose with white text.
5. Open Settings → Theme:
   - Verify the Love and Default theme preview cards show the Peach Sakura Pink palette (`#FFF8F6`, `#FFE3EA`, `#FFB3C6`, `#F28BA8`).
   - Verify switching between themes functions correctly, and non-default themes (Miku, Dark) remain intact.
