# Acceptance

- 设置页分别显示“默认工作区目录”和“当前 session 所属工作区”，二者不会互相冒充。
- 选择目录并点击“设为默认工作区目录”后只更新持久化默认值，当前 session 路径不变。
- 点击“重置为 Diva 默认目录”后，目标为当前 profile 配置目录下的 `workspace`，不存在时自动创建。
- 聊天入口选择目录后切换到目标 workspace 的 session authority，默认工作区配置保持不变；
  既有 session 不会被改绑，入口显示所选目录名。
- 未显式选择工作区时，入口显示“默认工作区”，runtime 使用已保存的默认目录。
- 保存或重置失败时保留当前默认值、当前 session 和页面输入，不显示成功反馈。
- session 工作区切换失败并回滚时，旧路径及“默认/显式选择”来源标记均保持不变。
