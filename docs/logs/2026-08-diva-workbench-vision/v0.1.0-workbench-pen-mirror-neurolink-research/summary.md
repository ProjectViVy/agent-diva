## 状态

Research / Proposal。用户已认可总体设计；本迭代未授权生产实现。

- 新增完整研究包，统一 Workbench、Neuro-Link、PEN、Mirror 和 Companion Node 的词汇、
  领域边界与目标架构；
- 明确撤回“Neuro-Link 是 PEN 传输层”的早期推测，将其冻结为可承载完整 DIVA 前端的
  Owner/Frontend Interface；

  Tool/Channel/Agent/Resource/Event/UI 投影；
- 将现有 Mate 定位为首个 Mirror 胚胎，并提出语义 Presentation Event 迁移路线；
- 提出手机优先的 Companion Node、Local Guardian、Sensor PEN、Observation/Moment/
  Memory 分层和 ExperienceEvent 候选模型；
- 对照当前 agent-diva、旧工作台资料、OpenFang Hands、Hermes、A2A、MCP、WIT、
  OCI 和 Sigstore；
- 更新研究索引，并在 TODOLIST 登记工作台/外接/具身总 Epic，重写 Neuro-Link Epic；
- 未修改生产 Rust、GUI 或配置代码。

## 关键结论

DIVA Core 保留认知连续性和治理；Neuro-Link 是神经/前端接入面；PEN 是手和外部器官；
Mirror 是脸与身体；Workbench 是组织这些系统的产品壳；Companion Node 是手机/设备上的
生活部署形态。共享包和 Supervisor 基础设施，但不压平不同协议与领域语义。
