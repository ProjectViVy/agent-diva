# Rulings

Ruling: split repair admission from acceptance admission — the existing full App/ack/production canonical fixture suffices to reproduce and repair user-source loss; native GUI, live models and reflection/recall are not inputs to that repair. Cost if wrong: development tests could miss a product-only issue; therefore every final product gate and same-candidate revalidation remains mandatory.

Ruling: bind missing task-local INOFY path to the exact already-pinned module cache — removes an environment-layout defect without dependency changes. Cost if wrong: an environment reset removes the prerequisite; record the absolute target/version and require reconstruction plus rerun before relying on it.
