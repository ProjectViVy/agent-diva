# 验收方案：聊天栏宽度与消息流居中对齐优化 (v0.0.1-chat-width-optimization)

## 验收目标
验证主界面聊天区域在不同视口宽度下的排版一致性，确保输入栏与消息流在中轴线上对齐，且蜜桃樱花粉配色系统不受影响。

## 验收步骤
1. **启动界面**：
   在浏览器或桌面端打开聊天界面（如 `http://127.0.0.1:4310/`）。
2. **大屏视图检查（窗口宽度 > 1200px）**：
   - 观察底部输入框：不再横向撑满整个窗口，而是约束在 52rem（832px）居中位置。
   - 发送一条短消息（例如“你好”）：气泡紧凑包裹文字，靠右对齐在 52rem 中轴列的右边缘；左侧助手回复靠左对齐在 52rem 中轴列的左边缘。
   - 输入框、消息列表与上方活动计划栏（如有）保持统一的左右边界中轴线。
3. **窄屏与窗口拉伸检查**：
   - 将浏览器窗口宽度缩小到 600px~750px。
   - 观察输入框与消息气泡：自然占满窗口，输入框左右各保留 16px 间隙，无横向滚动条，内容阅读流畅。
4. **配色检查**：
   - 蜜桃樱花粉（Peach Sakura Pink）默认主题色彩、深粉按钮对比度、卡片与侧边栏圆角依然保持正常。
