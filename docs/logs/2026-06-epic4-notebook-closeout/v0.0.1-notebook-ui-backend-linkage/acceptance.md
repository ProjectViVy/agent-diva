# Epic 4 Notebook Linkage Acceptance

1. Open Notebook with at least one valid report and at least one malformed report file in the report directory; valid reports should still render in the list.
2. Open a report, search session history in the Notebook detail pane, and select one or more returned session hits.
3. Create a Notebook proposal preview and confirm the selected session evidence appears in the preview evidence list.
4. Submit the proposal and open it in Evolution; the target proposal detail should load after the inbox refresh.
5. Trigger a preview request that fails and confirm the old preview content is not left visible for the new action.
