# v0.2.1 验收步骤

前置:重建并重启网关 + GUI(`release.md`);确保已有一个市场安装或手动上传的技能,
以及一个 Evolution 生成(已接受提案)的技能。

1. 打开 设置 → 技能管理 → 已安装。
2. 市场安装/手动上传的技能:右侧显示红色“删除技能”按钮,**不**显示“Evolution 管理”。
3. 点击删除 → 弹出确认框(标题“删除技能”,正文含技能名)→ 确认后技能从列表消失,
   出现成功 toast;取消则技能保留。
4. Evolution 生成的技能:仅显示“Evolution 管理”提示(盾牌图标,不可点击),无删除按钮。
5. 内置技能:无删除按钮、无 Evolution 提示。
6. 技能名显示为干净 slug,不再出现“:evolution 管理”式误读文案。
7. 提示框第二行为新文案(市场/手动技能可在此删除;Evolution 技能去 Evolution 管理)。
8. 切换英文界面,上述文案均有英文显示(Managed in Evolution / Delete skill 等)。
