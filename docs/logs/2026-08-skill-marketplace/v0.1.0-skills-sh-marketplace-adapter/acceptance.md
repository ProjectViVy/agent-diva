# v0.1.0 skills.sh Marketplace Adapter — Acceptance

## 前置

1. 已重建并重启网关与 GUI（见 `release.md`）。
2. 机器可访问 `https://skills.sh`（或已设置
   `AGENT_DIVA_SKILLS_MARKETPLACE_URL` 镜像）。

## 验收步骤

1. 打开 设置 → 技能 → 「技能市场」标签页。
   - 预期：空态提示「输入至少 2 个字符，搜索 skills.sh 技能市场」，
     不再出现旧的分类/信任等级筛选。
2. 搜索框输入 `commit`（或任意 ≥2 字符关键词）。
   - 预期：约 0.3s 防抖后出现结果卡片，按安装量降序；卡片展示技能名、
     `owner/repo`、安装数（如 311.9k）。
3. 任选一个未安装技能，点击「安装」。
   - 预期：按钮进入「安装中...」，成功后变为「已安装」并禁用；
     切到「已安装」标签页可见该技能（含 SKILL.md 内容）。
4. 再次对同一技能点击安装（或搜索后查看）。
   - 预期：按钮保持「已安装」禁用状态；直接重复安装返回冲突提示，
     不会覆盖既有技能。
5. 断网或搜索单字符 `a`。
   - 预期：单字符不触发请求；网络错误时显示错误框与「重试」按钮。
6. 回归：在「已安装」标签页上传 ZIP 技能、编辑/停用/历史功能不受影响。

## 已知边界

- skills.sh 无分页/分类接口，结果为单次模糊搜索（上限 50，默认 20）。
- 仅支持安装目录收录的公开技能；私有仓库技能不在范围内。
