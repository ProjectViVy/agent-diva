# v0.2.2 验收步骤

前置:重建 GUI 并重启(v0.2.1+ 网关);确保环境中同时存在 Evolution 托管技能
(已接受提案)与市场/手动安装的技能。

1. 打开 Evolution → Skills 标签。
2. 列表**只显示** Evolution 托管技能;市场安装、手动上传、内置技能均不出现。
3. 若环境中没有任何 Evolution 托管技能,显示“尚无 Evolution 管理的 Skill。”。
4. 对列表中技能执行编辑/停用/硬删,行为不变。
5. 打开 设置 → 技能管理 → 已安装:安装类技能仍可见且可删除(回归 v0.2.1)。
6. 待审请求标签行为不变(提案列表与技能列表过滤相互独立)。
