## 精选榜单（新）

1. 打开 设置 → 技能 → 技能市场标签页，**搜索框留空**。
   - 预期：显示「精选推荐（skills.sh 榜单）」标题与快照日期，
     卡片网格按安装量降序，首条应为 `vercel-labs/skills/find-skills`。
2. 点击任一精选卡片的安装按钮。
   - 预期：走真实 skills.sh 下载安装；成功后按钮变「已安装」且禁用。
3. 在搜索框输入 2 个以上字符。
   - 预期：精选列表切换为实时搜索结果；清空输入后恢复精选列表。

## 搜索与安装回归

4. 输入 1 个字符：不发请求，显示搜索提示。
5. 输入有效关键词（如 `commit`）：返回结果并按安装量排序。
6. 重复安装同一技能：提示安装失败（409 冲突语义）。
7. 断网或上游异常时搜索显示错误框且可重试；精选列表不受影响（离线内嵌）。

## 通过标准

以上 1–7 全部符合预期即视为通过；结果回填 TODOLIST
