# 验收步骤

1. 在普通聊天中提出一个需要多步执行的任务，确认 Agent 可调用 `update_plan`。
2. 确认界面显示“任务清单”，状态依次使用待处理、进行中、已完成语义，而不是显示为 Plan mode 方案。
3. 在工具完成和清单事件顺序接近时，确认最终回复仍正常出现，loading/typing 状态结束，界面不再卡死。
4. 确认一次清单最多只有一个 `in_progress` 项；多个进行中项目会返回明确工具错误。
5. 确认旧 PascalCase 状态载荷仍能正常渲染。
6. 确认调用 `update_plan` 不会自动修改仓库根目录 `TODOLIST.md`；持久 backlog 仍遵守项目协议单独维护。

自动化证据见同目录 `verification.md`。
