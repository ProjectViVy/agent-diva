# UX Decision Log

> UX: agent-diva-pro 自进化 + 沙箱 UI
> Created: 2026-06-02
> Source: prds/prd-my-project-2026-06-02/prd.md

## Session 2026-06-02

1. **视觉策略**: 完全继承现有 agent-diva-pro GUI 视觉系统。不新增颜色族、不扩展 yandere 调色板、不引入新字体。所有新组件使用 CSS 变量覆盖四主题。
2. **卡片位置**: ChatView 内联，在现有 tool 消息渲染区插入。决策卡/Todo卡/审批横幅均为消息流内组件，不跳出 Chat 页面。
3. **记事本布局**: 参考 Journal 的双栏模式（280px 左列表 + 右详情）。三标签：日报/周报/月报。
4. **设置布局**: 单栏表单，分组卡片。SelfEvolution 包含自进化控制 + 学习策略 + Memory Changelog + 沙箱设置四个分段。
5. **审批超时**: 5 分钟自动拒绝。最后 60 秒显示倒计时。键盘 Enter/Escape 快捷键。
6. **Todo 行为**: 手动勾选即时更新。全部完成后 3 秒自动折叠。写入失败回退状态。
7. **沙箱模式变更**: 显示黄色提醒条，不阻断操作。需重启 gateway 的决策标记为 [ASSUMPTION]。
8. **四主题兼容**: 所有新组件通过 CSS 变量接入 Love/Dark/Default/Miku 四主题，无需额外配置。
9. **操作反馈**: 按钮 hover scale(1.02) + brightness(1.1)，active scale(0.98)。保存成功 checkmark 1.5 秒。失败 toast。
10. **Do's and Don'ts**: 新卡片不用毛玻璃（保留给侧边栏）；风险等级颜色+文字双重表达；不引入装饰性动画。
