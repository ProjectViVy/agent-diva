## 一句话定位

**Diva 终极形态 = 人类式工作台**。
桌面摆着电脑、手机、音乐盒、游戏机、小说架……
agent 在工作台前坐着，**保留最强 harness 能力**，其他能力**能外接就外接**。

## 核心主张

| # | 主张 | 反例 |
|---|------|------|
| 1 | **Microkernel + 插件宇宙**：能外接的全部外接 | 龙虾：什么都内置 = 体积臃肿 |
| 2 | **按需编译**：需要什么装什么 | 龙虾：单体编译 |
| 3 | **保留最强 agent 能力**：harness 不断被挑战更优雅 | 通用框架的妥协感 |
| 4 | **工作台 = 视觉隐喻 + 架构哲学**：桌面图标 = 已安装能力 | 传统"控制台"界面 |
| 5 | **主人通道 vs 群聊场景 = 两种本质**：权限、信任、记忆策略完全不同 | 把 QQ 群当主人通道 |
| 6 | **群聊不能直接进 Mentle**：必须有"环境层"做前置过滤 | 100% 群消息入记忆 = 全废料 |
| 7 | **环境层协议无关**：能接 Hermes / 龙虾 / Diva | 平台耦合 |
