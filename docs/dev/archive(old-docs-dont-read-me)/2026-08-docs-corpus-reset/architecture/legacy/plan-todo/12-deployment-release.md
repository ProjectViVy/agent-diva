# 部署与发布

这是本地应用功能，无独立服务部署。发布采取兼容读取、分阶段启用：

1. 发布能读取旧 Plan/TODO、但尚未强制新语义的版本。
2. 默认新会话使用 workflow v2；记录计划提交、批准冲突、工具拒绝、TODO 物化的匿名结构化指标。
3. 观察一个发布周期后再考虑淘汰旧 `todo_write` 计划态语义。

发布前检查：

- [ ] `just fmt-check && just check && just test` 通过。
- [ ] 旧序列化 fixture 可读，新 fixture 可由旧 GUI 安全忽略新增字段。
- [ ] 计划态对写文件、shell、MCP、子代理的拒绝 E2E 通过。
- [ ] 批准后执行与回退到修订计划的 E2E 通过。
- [ ] release note 说明：TODO 变为可选执行清单，不再是计划阶段的必选副作用。

若出现错误拒绝，可暂时回退为 workflow v1 的兼容读取路径；绝不以放宽计划态写权限作为故障处置。
