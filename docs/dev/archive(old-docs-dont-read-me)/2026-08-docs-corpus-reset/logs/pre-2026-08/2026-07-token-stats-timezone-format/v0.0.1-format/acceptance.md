# Acceptance

1. Recompile and start `agent-diva-gui`.
2. Open the Token Statistics panel.
3. Verify that the time labels under the trend chart and the tooltips when hovering over the chart bars show localized times (e.g. `01:00` or `07-14`) instead of raw UTC strings (e.g. `2026-07-13T17:00:00+00:00`).
