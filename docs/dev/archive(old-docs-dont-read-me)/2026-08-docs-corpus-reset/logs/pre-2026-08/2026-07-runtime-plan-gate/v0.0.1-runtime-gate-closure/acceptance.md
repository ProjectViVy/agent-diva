# Acceptance

1. Submit a plan and verify the following ordinary message exposes Inspect-only tools while approval is pending.
2. Attempt a file write, shell command, network/MCP/custom tool, spawn, cron, or TODO write; each must be denied before execution.
3. Approve the displayed revision through runtime control and verify Execute tools return on the next iteration.
4. Complete, fail, or partially complete the active plan, then send an ordinary message and verify normal tools remain available.
5. Confirm the approval response contains the same plan revision and an immutable receipt.
