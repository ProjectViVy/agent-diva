# Acceptance

## Acceptance Steps
1. Make sure `agent-diva-manager` is compiled with the latest changes and running.
2. Open `agent-diva-gui` and initiate a chat conversation with a provider like DeepSeek that uses the OpenAI-compatible streaming API.
3. Once the conversation is complete, navigate to the Token Statistics panel.
4. Verify that the daily token usage count has correctly incremented rather than remaining at `0`.
