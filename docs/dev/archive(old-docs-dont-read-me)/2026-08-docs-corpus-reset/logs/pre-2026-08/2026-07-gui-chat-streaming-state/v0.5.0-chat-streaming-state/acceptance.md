# Acceptance

1. Start a thinking-mode request: the reasoning card and loading dots appear as distinct status areas.
2. Start a tool-using request: only the running tool card shows while the tool executes.
3. Stop before any response text arrives: no blank assistant bubble remains and DIVA says “已停止。需要我做什么呢？”.
4. Stop after partial response text arrives: the partial text remains without a second stop message.
