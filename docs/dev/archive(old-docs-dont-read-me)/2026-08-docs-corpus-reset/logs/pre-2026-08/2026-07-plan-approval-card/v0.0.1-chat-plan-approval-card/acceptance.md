# Acceptance

1. Enable Plan mode and submit a request that produces a plan.
2. Confirm the current chat page shows the plan card after the plan reaches `AwaitingApproval`.
3. Confirm the card shows the goal and ordered steps.
4. Select `预览详情` and confirm strategy, rationale, expected output, or todo detail is visible.
5. Select `执行计划` and confirm the card transitions to the existing execution progress state.
6. Generate another plan and select `撤销`; confirm the card disappears and the active plan is removed.
