# 验收步骤

1. 打开 Notebook 视图并选择任一报表。
2. 点击 `Create SOP Proposal`。
3. 确认前端先进入 proposal preview，而不是直接提示写入成功。
4. 提交后确认 UI 表达为“提案已创建，等待 Laputa 审查”。
5. 在 Evolution Inbox 中确认可以打开对应 proposal。
6. 验证提案提交前后，仓库根或工作区中不存在新的 `SOUL.md`、`IDENTITY.md`、`memory/MEMORY.md`、`memory/HISTORY.md` 直写副作用；authority 变更只能在 Laputa 审批并 apply 后出现。
