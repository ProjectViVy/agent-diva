# Acceptance

From a user/product perspective:

1. Sidebar icons look lighter and better balanced against 14px labels.
2. Nested items under Capabilities / Tools read as secondary (smaller, quieter).
3. Collapsed rail still easy to click; icons not cramped in the hit target.
4. Active route remains easy to spot (brand icon color + existing background).
5. No regression in navigation targets or labels.

Pass when the above hold across expanded/collapsed and at least two themes.
