# Release

Release method:
- No deployment action performed in this iteration.
- The change is a library-level AutoDream API and filesystem contract update.

Operational notes:
- Daily reports are written to `.agent-diva/autodream/reports/daily/{YYYY-MM-DD}.md`.
- Weekly reports are written to `.agent-diva/autodream/reports/weekly/{YYYY-Www}.md`.
- Monthly reports remain outside AutoDream authority and are not written by this API.
